# 主站运行白名单与发布约定

当前运行清单为仓库根目录的 `runtime-manifest.json`。使用 `python3 -B scripts/runtime_snapshot.py export output/runtime` 可导出 238 个运行文件与 5 个相对链接；发布只上传该清单。

`publish_astra.py` 保留现有受保护发布逻辑：先核对逐文件哈希、发布前状态与已有备份，再切换主站版本；失败时按已绑定的状态恢复。它依赖服务器上的独立上传目录、新生成的发布 request、原配置备份与既有权限。仓库不保存实际服务器状态或可重复执行的旧 request。

`nginx-home.locations.conf` 是当前主站路由片段，只适用于原有 server 上下文。子站服务和父级配置由各自维护流程负责。这个文件不是完整 Nginx 配置，不能直接覆盖共享主机配置。

发布前读取实际公共链接、配置与文件状态；精确备份当前版本，准备只含运行白名单的候选并核验回滚条件。上线后检查 HTTP/HTTPS 页面、资源和各相关入口。若现有线上版本已与本次清单逐字节一致，只记录验证结果，无需重复切换、重载或重启。
