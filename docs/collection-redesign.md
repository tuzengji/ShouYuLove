# 分类页面改版说明

2026-09-29。沿用灰色石膏浮雕、衬线标题和现有原生技术栈；未引入框架或依赖。

原来四个作品混合出现在一个目录，无法区分手语工具与校园服务。现由 projects.json 的 collection 字段分流至「核心创意」和「其他作品」两个独立页面：首页作品集锚点显示两组内容，分类页展示作品名、用途和已知作者。顶部导航只保留「关于心创组」「作品集」，分类当前项使用细线标记。

设计取向：保留浮雕滚动与作品卡片动效，手机采用低质量模型与原生滚动；移除深色模式、简洁预览、作品集弹层和独立照片展示。

验收包含生成器边界、真实浏览器导航与新标签页、桌面与手机、减少动态效果、部署包逐文件哈希。没有改变三个业务子站与拼好课本身。
