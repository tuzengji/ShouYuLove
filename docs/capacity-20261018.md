# 2026-10-18 主站并发访问压测

当前主站的主要限制是公网资源传输。以“新用户首次打开首页，30 秒内进入首屏主场景”为标准，本轮只有单人冷加载全部达标；两人同时打开用时 29.8、36.7 秒，三人用时 39.4、44.3、55.7 秒。服务器仍能正常响应请求，等待主要发生在模型、字库图集等资源下载期间。

作品集的目录先显示，五人同时首次进入时，目录在 1.1–3.3 秒内就绪，完整三维背景在 39.4–53.0 秒后完成。若同学集中打开网站以寻找作品入口，直接使用 [作品集](https://shouyulove.cn/portfolio/) 能更快进入项目。

## 公网浏览器结果

测试版本为 `20261017T162339Z-astra-home`。从同一台客户端发起，模拟 390 × 850 手机视口，每位冷加载用户使用独立、无缓存的 Chromium 会话；实际连接为 HTTP/2。以下是短时测试结果，不是服务等级保证，也不表示网站只能容纳这些在线人数。

| 场景 | 同时打开人数 | 目录就绪 | 首页主场景／作品集完整背景就绪 |
| --- | ---: | ---: | ---: |
| 首页首次打开 | 1 | 使用原生加载页 | 17.7 秒 |
| 首页首次打开 | 2 | 使用原生加载页 | 29.8、36.7 秒 |
| 首页首次打开 | 3 | 使用原生加载页 | 39.4、44.3、55.7 秒 |
| 首页随后刷新，复用缓存 | 2 | 使用原生加载页 | 3.38、3.46 秒 |
| 作品集首次打开 | 1 | 0.38 秒 | 12.1 秒 |
| 作品集首次打开 | 5 | 1.13–3.28 秒 | 39.4–53.0 秒 |

首页使用 `syl-native-ready` 判定首屏主场景可进入，不要求后续滚动场景全部下载。作品集使用 `syl-portfolio-readable` 和 `syl-portfolio-background-ready` 分别判定目录就绪和完整背景就绪。目录本身是 HTML，这个就绪标记是保守的时间点，不能用完整背景耗时替代作品入口可用时间。

首页单人冷加载阶段接收约 12.83 MB，两人共 26.48 MB，三人共 39.50 MB；三组的浏览器总接收速度约 5.7–5.8 Mbps，没有随人数增长。作品集单人完整加载接收约 7.44 MB，五人共 37.20 MB。这里 MB 按一百万字节计，数据是截至各阶段结束的浏览器接收量，包含页面请求及已开始的后台资源，不是整个站点文件总量。

两人首页冷加载期间，服务器 CPU 平均约 0.36%；三人时约 0.57%，可用内存均超过 13 GB。五人作品集阶段 CPU 平均约 5.66%，仍有余量。网卡发送数据包含 TLS、协议开销、可能的重传和其他连接，与浏览器接收量口径不同；没有把网卡瞬时峰值当作可持续公网容量。

缓存对重复访问有效：两位首页用户刷新后共新增约 97 KB 接收数据，分别复用了 77、74 个缓存资源，进入主场景约 3.4 秒。已加载后继续浏览与集中首次下载的带宽需求不同，不能根据冷加载人数推算最大在线人数。

## 页面请求承载

在服务器本机通过回环 HTTPS 请求正式 Nginx，每档并发重复三轮，校验 gzip 解压后的 HTML 哈希。共完成 1,566 个请求，无 HTTP 错误、超时或内容不匹配。

| 页面 | 最大已测并发 | 该档请求数 | P95 完成时间 | 结果 |
| --- | ---: | ---: | ---: | --- |
| 首页 HTML | 200 | 600 | 0.443 秒 | 全部 200，内容一致 |
| 作品集 HTML | 100 | 300 | 0.172 秒 | 全部 200，内容一致 |

200 并发首页这一档，包含压测生成器在内的主机 CPU 达到 73.5%，触发预设的 70% 停止条件，因此没有继续加压，也没有再测 200 并发作品集。这是停止测试的边界，未测得 Nginx 的故障上限；回环测试不经过公网带宽。

另从公网依次同时请求 1、10、30、50 份作品集 HTML，全部成功。50 请求时 P95 为 0.214 秒、最慢 0.218 秒。该轮使用 HTTP/1.1 和 gzip，只有 HTML，没有下载字体、图片和三维背景；不能据此声称 50 人完整冷加载也能在这个时间内完成。

## 范围与停止条件

- 浏览器每阶段最多 60 秒、累计接收最多 64 MiB；出现 5xx 立即终止该阶段。
- 回环请求出现非 200、内容不匹配、P95 超过 1 秒或主机 CPU 超过 70% 即停止加压。
- 主站实测到 3 个同时冷加载用户、作品集实测到 5 个；没有继续增加完整资源下载人数。真实教室网络、不同手机性能和更高峰流量仍会改变耗时。
- 请求统一使用 `ShouYuLove-QA-Capacity`，沿用现有 QA 过滤，不计入普通访问统计。没有压测词典后端、AI API、登录或其他项目业务接口。

本轮监测窗口内，QA 日志没有 429、499 或 5xx；该窗口没有记录到非 QA 访问，不能据此评估繁忙时段对其他真实用户的影响。测试结束后首页、作品集及七个子项目入口均返回 200；网站发布目录、24 份 Nginx 配置哈希、8 个后台服务 PID 均与压测前一致。

压测没有修改网页、限流、带宽或运行服务。源码与测试原始记录保存在本机 `output/deployment/capacity-20261018/`；汇总数据见 [验证数据](evidence/capacity-20261018.json)。本次只同步说明和证据到仓库及服务器私有维护目录。
