# Immersive Garden 风格改编记录

2026-09-29。参考 https://immersive-g.com/ 。按用户提供的 ai-website-cloner-template 技能研究流程，固定版本 f50066df3f4bdca057d3b239be6f49f17724bb13。使用真实 Chromium 浏览器采样、读取公开 CSS/前端参数、逐状态复刻和独立复查。沿用主站原生技术栈，不套用技能的 Next.js 默认脚手架。

## 私有参考复刻

研究在 `output/immersive-research/`，可运行首页复刻在 `output/immersive-clone/`。桌面使用18项目/39媒体布局，1440×900总高38498px；真触控手机使用19媒体，390×844总高17228px。原站桌面窗口直接缩窄仍有39媒体，不能拿它代替手机设备分支。菜单、页脚使用各自独立模型与材质，不以首页背景简单变暗代替。

验证材料包括布局表、行为表、截图、场景规格与 comparison 下的逐项审查。原网站图形、品牌、模型、音视频只保存在本地私有研究目录；菜单中超出首页研究范围的详情链接指向原网站。该研究不是51个项目详情页的完整镜像。

## 公开主站的保留与改编

| 参考特征 | 主站实现与改编 |
| --- | --- |
| 灰色石膏表面、局部浮现 | 公开主站暂时直接采用参考站公开的 relief 渲染器与本地浮雕模型，保留指针流场、法线、遮蔽和滚动挤出；素材说明见 `home-assets/licenses/IMMERSIVE-G-REFERENCE.txt` |
| 十二列空间排版 | 桌面12列/16px间隔，品牌与身份在首屏中轴，项目示意图与文字卡片连续排列；手机6列后转内容自然流 |
| PSTimes衬线字体 | 全站中英文统一使用自托管 PSTimes / Noto Serif SC / Songti 衬线字体栈，标题通过字号和字重建立层级，英文字距保持舒展 |
| Lenis惯性 | 桌面lerp .05，触屏保留原生滚动；无滚动劫持/强制吸附 |
| 文字与媒体显现 | GSAP ScrollTrigger；展示标题blur5→0、y36→0，正文仅短距离移动，进入阅读区即保持完整清晰 |
| 图片视差 | 不再单独展示照片；四项目用本地 CSS 绘制的紧凑几何示意图，并保留卡片轻微位移 |
| 悬停反馈 | 项目示意图轻微缩放、指针位移与SVG液态扰动，始终显示用途与设计者；手机不依赖hover |
| 快速浏览缩放 | 快滚速度驱动1/(1+3×fast)媒体缩放与大标题；背景zoom响应，停止后恢复，DOM高度与当前位置不跳 |
| 作品集导航 | 顶部只保留「关于心创组」「作品集」；作品集直接滚动到首页的「核心创意」「其他作品」，分类页保留两组切换 |
| 连续项目陈列 | 六件作品使用小尺寸透明 SVG logo 与文字卡片连续排列，滚动时可连续看到多个项目，不再以大幅媒体撑满一屏 |
| 成员缩放总览 | 12 位第一届成员使用两列大字卡片；进入视口时由模糊、缩小状态快速放大，形成参考站的滚动总览节奏 |
| 独立花园页脚 | 改为“边界”原文和品牌，原创植物暗色退场；不移植原工作室联系/订阅功能 |
| 声音与主题 | 公开主站不加载声音，也不提供深色模式、简洁预览或作品集弹层；系统 `prefers-reduced-motion` 仍提供静态回退 |

页尾收束按原站的接触页节奏处理：先用低存在感的小字号呈现边界，再进入独立的纯黑 `footer-black-stage`，黑色阶段只保留「以手予爱 ShouYuLove」。页尾不再显示多余联系方式、社交入口或项目按钮。

因此公开主站是经过内容适配的风格改编；不能用参考稿的像素/高度校验结果宣称品牌站逐像素相同。

## 装饰场景成本与回退

参考 relief bundle 约533KiB、主控制器约135KiB；高质量模型约5.99MB、低质量模型约4.74MB，GPU另持渲染副本。公网首次加载取决于服务器连接速度，场景就绪前正文保持可读；本地 Chromium 桌面与 390×844 手机均完成场景初始化。

减少动态效果采用浮雕静态绘制并关闭 Lenis/GSAP 时间线；不支持 WebGL 时保留纸面背景。正文从不由 Canvas 绘制，关闭脚本仍完整显示六件作品、12 位成员与两个目录。
