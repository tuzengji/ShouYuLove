# Daylight 动效测量与实现映射

用户要求以原站动效为准，允许重新设计不适合心创组的视觉元素。2026-09-27 检查 live DOM、计算样式、桌面与手机截图，以及公开提供给浏览器的页面脚本。

## 依据

- 原站：https://daylightcomputer.com/
- 浏览器脚本：`page-8b740ac8b83cd657.js`、`8116-ffc0b80558d3e14d.js`、`4326.6e3d27f8e034110b.js`、`layout-764e9b4c694b17f5.js`。
- 本地参考文件位于 `output/daylight-study/source/`，逐阶段截图为 `output/playwright/reference-motion-*.png`。
- 官方实现文档：https://gsap.com/docs/v3/Plugins/ScrollTrigger/ 、https://github.com/darkroomengineering/lenis 。

## 时间轴

| 动效 | 原站测量 | 实现 |
| --- | --- | --- |
| 滚动惯性 | Lenis `lerp: .145`, `wheelMultiplier: 1` | 相同参数，触摸保留原生行为 |
| 首屏停驻 | 桌面 200vh，内层 sticky 100vh | 对应 200svh / 100svh，18px 外边距，24px 圆角；按用户后续要求，手机也保留日光变化 |
| 首屏光线 | 滚动映射 Canvas 0–169 帧，明亮草坪逐渐变暗 | 相同 0–169 帧区间、起止和缓动；Canvas 根据同构图的清晨、金色傍晚、蓝调夜色关键图逐帧合成。日光方向和色温随滚动过渡，支持逆向还原。原站平板的商品帧不用于主站 |
| 大字停驻 | 500vh，桌面与上一节重叠 100vh | 对应 500svh；使用短标题与一段介绍，手机与桌面一致 |
| 第一轮字 | 15–35%，每字 opacity 0→1、y -10→0、z 25→0、rotateX 10→0，power3.out；duration 占 2/6，stagger 占 4/6 | 相同参数；中文按字符拆分，保留完整无障碍标题 |
| 第一轮离场 | 41–51% 透明度下降 | 标题与介绍整体持续显示至 76%，随后淡出 |
| 第二轮字 | 50–70%，duration 占 4/6，stagger 占 2/6 | 移除重复的第二轮标题；唯一介绍段落在 28–40% 显露 |
| 第二轮离场 | 76–86%；78–99% 遮罩离场 | 相同区间，使用 CSS clip-path 横向擦除 |
| 横向展陈 | 桌面上移 230vh，sticky 100vh，panel 间距 20vw；面板总 vw 对应容器总 vh | 相同几何映射，由实际项目数量计算总宽度与滚动距离 |
| 图片视差 | 缩放 1.2，随滚动反向位移 | 同倍率，使用 containerAnimation 联动横向展示 |
| 移动端展陈 | 1024px 以下改为纵向 | 相同断点；项目直接上下浏览 |
| 光线转场 | 400vh，文字 5–25%，颜色 40–50%，缩小 50–65%，侧移 70–92.5%，说明 85–100% | 保留归一化阶段；用橙色纸面显露湖光图，仅一个文案节点从中心移动至侧边，并在 65–72.5% 淡出、85–100% 再显露。使用 CSS 透视代替商品 WebGL 模型 |
| 页尾 | 内容分层进入 | 文字与内容分层显露；不编造商品评价与用户证言 |

## 适配边界

这里复现的是滚动几何、动画阶段、逐字变换与展示交互；并非商品画面逐像素相同的镜像。自然摄影、文字、字体、项目图标与橙色纸面是为心创组重新设计的元素。首屏采用 3 张同构图关键光照图的逐帧插值，并通过正午亮度曲线与横向移动的暖光场完成过渡；没有使用纯黑色遮罩来代替一天的变化。原站 Canvas 商品帧序列和 WebGL 平板不直接进入生产文件。只在研究目录中保留原站截图和源文件作为动效依据。

静态完整目录始终存在，顶部「项目导航」和首屏三个快捷入口可直接使用。关闭 JavaScript、选择「简洁浏览」或系统开启 reduced motion 时，全部内容改为普通文档流，真实项目链接仍然可用。

2026-09-27 视窗适配：首屏取消 680/748px 固定最小高度，按实际视窗高度显示；矮窗口调整标题、间距和插图大小，窄横屏将首屏文字与快捷入口并排。滚动时长与日光阶段保持原参数。

深链接定位前同步 Lenis 的页面尺寸，避免首次加载动画布局时沿用静态页面的旧高度。桌面横向展陈使用 `overflow: clip`，避免浏览器原生片段定位额外改变容器的 `scrollLeft`，与 GSAP 位移叠加后将项目移出视野。
