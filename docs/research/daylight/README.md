# Daylight 首页研究与心创组改版

## 设计判断

这是面向手语学习者、社团成员与公益伙伴的社团介绍和项目导航首页。参考 Daylight 的自然摄影、浮动导航、宽松排版与滚动叙事，采用有自然光感的编辑式设计。DESIGN_VARIANCE 7 / MOTION_INTENSITY 6 / VISUAL_DENSITY 3。

此次为用户明确要求的视觉重做。使用「以手予爱 ShouYuLove」品牌，保留小标志、导航功能和全部项目真实地址；当前不招新，移除报名问卷；项目内容仍来自 `projects.json`。旧版完整源文件和预览产物已封存至 `主站版本归档/20260927-172721-创意小屋版/`，独立压缩包也在同目录。

## 页面结构与交互

1. **沉浸首屏**：品牌、浮动导航与项目快捷入口。文字和入口在图片上有独立对比度保护。
2. **关于心创组**：先逐字显露简短标题，再用一段话介绍归属与职责。
3. **横向项目展陈**：由 JSON 生成项目名称、一段介绍与无文字图标，不用网站截图。宽度、滚动距离和切换控件由面板数量计算。
4. **纸面转场**：沿用原站 400vh、着色、缩小、倾斜、侧移和介绍显露的时序，重新设计平板商品元素。
5. **完整项目导航**：普通 HTML 链接；项目大于 6 个时出现搜索和分类。
6. **心创组工作方式**：用「我们做什么」和「我们怎样协作」两段介绍工具开发、技术支持与项目小组协作；不展示分社架构、人名或报名入口。
7. **页尾**：品牌、回到顶部、全站明暗切换、简洁浏览。

Lenis 按原站参数平滑桌面滚轮，触摸保留原生行为。锚点按真实时间轴定位，浏览器前进后退可用。`prefers-reduced-motion` 下不加载动画包。简洁浏览与关闭 JavaScript 时，仍能阅读全部内容并跳转项目。更详细的参数及复刻边界见 [MOTION.md](MOTION.md)。

## 研究稿与素材边界

`output/daylight-study/` 是本地结构研究稿，参考图只用于此研究目录；它不是生产页面，也不属于部署文件。正式首页使用独立生成的自然氛围图、原有心创组品牌资产与本地开源字体。自然图不代表北京大学实景或真实活动记录。

部署范围维持 `index.html` 和 `home-assets/`，所有归档、研究截图、验证报告与中间稿均不部署。
