## 回退行为

一般服务在鉴权失败、余额不足、限流、上游服务错误或网络失败时，最多切换一次备用凭据；成功请求优先使用主用凭据。400、422 等请求格式错误不通过换 Key 重试。测试覆盖主用成功、主用失败后备用成功、备用也失败、无备用/重复凭据，以及不向第三方接口发送官方备用凭据。

HAICA 评测采用更窄的自动切换条件：上游明确返回 401、402、403 或 429，且尚未返回模型内容。已开始输出、网络中断或费用状态不明确的评测不重放。切换账号时重新上传原始图片，并分别用文件所属账号清理临时文件；失败请求与最终请求均有记录。Poetalent 对可能产生费用的首次失败保留预算预留，主备两次请求均受既有总预算约束。
