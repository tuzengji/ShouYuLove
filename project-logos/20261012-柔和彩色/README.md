# 柔和彩色项目图标

这是当前首页和作品集使用的图标套件。八个项目保留可编辑 SVG、1024px 透明 PNG、单色及反白版本；手语文化节沿用原卡通人物 PNG。

以 A 组造型为主，配色使用灰绿、雾蓝、豆沙、暖米、浅紫与浅金色。年终总结为「谢谢这一年」感谢章；传情绘意为用户选定的 B「心意小卡」，两张错开的卡片中带有豆沙色爱心。

- `selection.json`：已选方向与各图标含义。
- `palette.json`：配色数据。
- `variants/`：单色与反白版本。
- `index.html`、`总览.png`、`size-check.html`：套件预览与尺寸检查。
- `asset-checks.json`：素材检查记录。

彩色版建议至少 32px，16px 使用单色版。`scripts/build_content.py` 将透明 PNG 按可见图形统一留白，导出 640×640 方形纹理，首页和作品集共用；原图不直接覆盖已发布的 immutable 地址。

当前图像缓存版本为 `syl-v1-1-charades-cards`。替换素材时更新 `RUNTIME_VERSION` 及引用图像的模块和数据桥版本，并核对桌面、手机及小尺寸效果。五个相关子站已同步项目标识、浏览器图标和 Apple 触屏图标，词典独立服务未改动。

旧版素材保留在各自目录。完整页面约定和发布记录见 [作品集维护说明](../../docs/portfolio-maintenance.md)。
