# 项目标识

主站新标识的三个待选方向见 [以手予爱主站图标概念](20261012-主站概念/README.md) 和 [方案总览](20261012-主站概念/主站图标方案.png)。正式方向选定后，主站各页面的标签页图标、Apple 触屏图标与作品集安装图标使用同一图形和新的缓存地址。

当前九个项目使用 [20261012-柔和彩色](20261012-柔和彩色/README.md) 套件：八枚可编辑 SVG 与透明 PNG，手语文化节沿用原卡通人物。年终总结为「谢谢这一年」感谢章，传情会意为 B「心意小卡」。

`scripts/build_content.py` 将原图归一为 640 × 640，首页和作品集共用同一版本化资源，并继续使用 `styles/project-logo-mask.svg` 的边缘处理。

[20261012-统一曲线](20261012-统一曲线/README.md) 保留为历史素材；`20261004-轻盈版/` 与根目录旧素材由本机维护目录保存。页面约定与当前资源版本见 [作品集维护说明](../docs/portfolio-maintenance.md)。
