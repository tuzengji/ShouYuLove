# 以手予爱主站图标概念

用户已指出本轮黑白风格不符合现有作品图标。当前待选方案转到 [彩色重绘](彩色重绘/README.md)，采用现有图标的描边、低饱和填色与具象手掌造型；本页以下保留第一轮过程记录。

设计日期：2026-10-12。面向主站访客与心创组成员，图标用于网站标识、浏览器标签页和手机桌面；图形围绕「手、给予、爱」，沿用现有图标的圆润线条和柔和配色。

这是待选概念，不是已发布素材。当前主站的标签页图标仍由构建器从旧版素材复制；正式方向选定后，网页、favicon、Apple 触屏图标和作品集安装清单应使用同一图形，并换用新的缓存地址。

## 方向与取舍

最初比较了掌心托心、予字、两手相拥、手语动作线、掌心萌芽、指尖火花、SYL 简写、双手成桥、掌印留白和爱心书签。选出三个不同的图形方向；动作线与子项目以手寻语过于接近，书签接近词典，萌芽容易被读作植物，细碎的火花与掌印不适合标签页尺寸。

| 方向 | 图形想法 | 重点检查 |
| --- | --- | --- |
| A 掌心予爱 | 张开的手托起一颗心，表达把爱给予他人 | 手掌内部留白和小尺寸轮廓 |
| B 予字小印 | 以定制的「予」字作为品牌记号 | 字形读法与转折处的清晰度 |
| C 相拥成心 | 两条相向的手臂围出心形，表达伙伴相互支持 | 中央留白和上下交接处 |

黑白形态先检查轮廓与 16／32／64px 效果；配色参考现有墨绿、豆沙、暖米套件。图案内不加入文字缩写、渐变、阴影或照片，保持缩小后容易辨认。

## 检查记录

三个方向已完成两轮 SVG 审查和渲染。第二稿调整 A 的心形实心表现、手掌曲线和居中位置，调整 B 的居中位置，打开 C 的两端间距；角度审查已无近似角度警告。概念中的描边在 SVG 缩放时随图形等比例变化。

`主站图标方案.png` 展示大图、真实 64／32／16px 小图与 A 的配色示意。预览图中的中文字采用主页已选狮尾四季春字体并转换为路径，避免预览环境缺少中文字体而出现方框。第一稿保留在 `*-v1.svg`，当前待选图形为 `*-v2.svg`。

选定后再制作正式彩色及小尺寸版本，接入主站构建，核对首页、心创组、作品详情和作品集的标签页图标，再推送仓库并发布到既有服务器。其他项目的已选标识保留。
