# 以手予爱 · 把爱递给你

2026-10-12 选定 A「把爱递给你」，按反馈将手掌改为更浅的暖米色。图形是一只伸出的手与一颗爱心，沿用作品集图标的圆润灰绿描边和柔和彩色填充。

- [可编辑 SVG](shouyulove.svg)：256 × 256，13 单位描边，等比例缩放。
- [透明 PNG](shouyulove.png)：512 × 512。
- [尺寸与同系列对照](preview.png)：包含 64、32、16px 效果。

| 部位 | 颜色 |
| --- | --- |

| 手掌 | `#f3dfcf` |

保留画布中的留白，不拉伸、不单独改变描边粗细。网页与标签页使用透明背景；手机桌面使用不透明浅底，由系统处理圆角。源文件保留描边，适合等比例网页渲染。

`scripts/build_content.py` 的 `brand_assets()` 从同一 SVG 生成 64px favicon、180px Apple 图标、192px 与 512px 安装图标，`brand_links()` 为各页面提供一致的引用。资源版本独立为 `syl-v1-1-giving-heart`。修改图案或颜色后更换 `BRAND_VERSION`，避免覆盖已缓存文件。

作品集安装身份仍为 `/projects/`，启动地址与范围仍为 `/portfolio/`。其他项目图标继续使用原套件。
